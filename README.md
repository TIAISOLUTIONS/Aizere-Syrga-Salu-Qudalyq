# Приглашение: Айзере — Сырға салу, Құдалық (22.11.2026)

## Шаг 1. Загрузка на GitHub и включение Pages
1. Создайте на GitHub новый **публичный** репозиторий (например `aizere-toi`).
2. Нажмите **Add file → Upload files** и перетащите ВСЁ содержимое этого архива
   (файл `index.html`, папку `assets` и остальные файлы) — именно содержимое, не саму папку.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В «Source» выберите **Deploy from a branch**,
   ветка **main**, папка **/(root)** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ-ЛОГИН.github.io/aizere-toi/`

## Шаг 2. Подключение Google Таблицы (чтобы видеть ответы)
1. Создайте новую таблицу на https://sheets.google.com
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте содержимое файла `google-apps-script.gs`. Сохраните (💾).
4. Нажмите **Начать развертывание (Deploy) → Новое развертывание**.
   - Тип (шестерёнка): **Веб-приложение**
   - Выполнять как: **Я (ваш аккаунт)**
   - У кого есть доступ: **Все (Anyone)**
5. Нажмите **Развернуть**, разрешите доступ своему аккаунту
   (если появится «Приложение не проверено» → «Дополнительно» → «Перейти к проекту»).
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
7. На GitHub откройте `index.html` → иконка карандаша ✏️ → найдите строку
   `var GOOGLE_SCRIPT_URL = "";`
   и вставьте ссылку между кавычками:
   `var GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/....../exec";`
8. **Commit changes**. Через минуту сайт обновится.

После первого ответа в таблице сами появятся листы:
- **Анкета** — время, имя, ответ (Иә, әрине / Жұбайыммен келемін / Келе алмаймын)
- **Тілектер** — время, имя, пожелание

## Как изменить тексты
Все тексты находятся в `index.html` — их можно поправить прямо на GitHub.
Дата для обратного отсчёта: строка `var EVENT_DATE = new Date("2026-11-22T12:00:00+05:00");`

> Если поменяете код скрипта в Apps Script — делайте **Развертывание → Управление развертываниями → ✏️ → Версия: Новая**, тогда ссылка останется прежней.
